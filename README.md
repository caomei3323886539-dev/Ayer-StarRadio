# Ayer Star Radio v0.6.2

从播放页或编辑歌曲资料进入「歌词精修工作台」。可载入歌曲现有时间歌词或导入双语 LRC。点击「读取波形」，拖动歌词编号，或使用方向键微调。使用「重复歌词」逐次试听并记录复核状态。间奏提示来自 LRC 中的间奏行或超过 19 秒的句间隔。

修订草稿按歌曲保存在当前浏览器，重新打开时自动恢复。应用前会检查原文、翻译、顺序和时长。无法解码波形时，仍可用时间轴、数字时间输入和浏览器支持的音频试听。


星光音乐空间：独立播放页、播放队列、歌词/LRC、排序、动态星光。

部署：将 index.html、sw.js、manifest.webmanifest、icon.svg 上传至 GitHub Pages 仓库根目录。

兼容性：继续使用 IndexedDB `ayer-star-radio` v2，保留歌曲、收藏、歌单。请勿清除站点数据。

注意：歌词存储在歌曲元数据中，浏览器可能限制后台播放。
